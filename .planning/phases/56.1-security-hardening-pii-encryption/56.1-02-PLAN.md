## Goals
1. **Tenant Context Standardization (`src/server/api/trpc.ts`)**:
   - Provide and export a shared helper `resolveTenantContext(ctx, requestedOrgId?)` that accurately evaluates:
     1. Super Admin impersonation cookie (`ctx.impersonatedOrgId`)
     2. Session active organization (`ctx.session.user.organizationId`)
     3. Request headers (`x-tenant-id`, `x-tenant-slug`)
     4. Verified membership check in `organizationMembers` for normal users, or bypass for `SUPER_ADMIN`.
     5. Graceful fallback to user's first organization if none specified.
   - Return `{ organizationId, role, isOwner, isAdmin }` and throw `TRPCError({ code: "FORBIDDEN" })` if unauthorized.
2. **Domain Router Migration**:
   - Replace all legacy `organizationMembers.findFirst({ where: eq(userId) })` calls in:
     - `src/server/api/routers/billing.ts` (all ~15 procedures)
     - `src/server/api/routers/inventory.ts` (all CRUD procedures)
     - `src/server/api/routers/automations.ts` (all rules and comms procedures)
     - `src/server/api/routers/apiKeys.ts` (list, create, revoke)
     - `src/server/api/routers/client-subscriptions.ts` (list, create, update, cancel)
     - `src/server/api/routers/webhooks.ts` (`getAppPortalUrl`)
   - Ensure all queries, updates, and deletes strictly scope to `tenant.organizationId`.
3. **Cross-Tenant Entity Validation**:
   - In `clientSubscriptionsRouter.createSubscription`: Verify `companyId` and `productId` actually belong to `tenant.organizationId`.
4. **Destructive Action Role-Based Access Control (RBAC)**:
   - Restrict `apiKeys.create` and `apiKeys.revoke` to `OWNER` or `ADMIN` roles.
   - Restrict `billing.deleteInvoice`, `billing.refundInvoice`, and `billing.issueCreditNote` to `OWNER` or `ADMIN` roles.
   - Restrict `webhooks.getAppPortalUrl` to `OWNER` or `ADMIN` roles.
   - Return `TRPCError({ code: "FORBIDDEN", message: "Requires Organization Admin or Owner privileges" })` when unauthorized.
5. **Full Regression & Production Build**:
   - Verify `pnpm test` passes for all 18+ test suites.
   - Verify `pnpm build` completes with 0 errors across all 55 routes.
