## Tasks

### Task 1: Settings & Administration Overhaul
- Redesign `/settings/*` views:
  * Profile settings with avatar upload and credentials form.
  * Organization settings with tenant info, timezone, and fiscal year.
  * Branding settings with primary color picker and logo upload.
  * Security settings with MFA / password management.
  * API keys and Webhook endpoints with secret reveal and copy triggers.
- Redesign `/admin/*` & `/superadmin/*`:
  * Tenant management cards, organization status pills, user role assignments.

### Task 2: Authentication & Onboarding Redesign
- Redesign `/login` and `/register`:
  * Centered glassmorphic auth cards, OAuth providers, input field icons, forgot password links.
  * Ensure inputs have `text-base` on mobile to prevent iOS Safari auto-zoom.
- Redesign `/onboarding`:
  * Multi-step progress bar (Workspace Setup -> Team Invites -> Preferences).
- Redesign `/` (Landing Page):
  * Flagship landing hero with modern typography, glassmorphic preview cards, feature grid, and live demo CTA.

### Task 3: Client & Public Document Portals
- Redesign `/c/[orgId]`:
  * Clean self-service customer portal with invoice list, payment status, and download links.
- Redesign `/public/invoice/[id]`, `/public/quote/[id]`, `/public/statement/[id]`:
  * Print-ready, responsive document viewer with company logo, line items table, and payment/approval CTA buttons.

### Task 4: System Edge Views
- Create `src/app/not-found.tsx`:
  * 404 illustration, clear heading, search or return-to-dashboard button.
- Create `src/app/error.tsx`:
  * Error boundary card with error message, retry trigger button, and support link.
- Create `src/app/loading.tsx`:
  * Skeleton loader with animated pulse matching dashboard layout shell.

### Task 5: End-to-End Quality Gate & Staged Deployment
- Run `pnpm biome check --write` to ensure zero linting or formatting errors.
- Run `pnpm vitest run` to ensure all 21/21 tests pass cleanly.
- Run `pnpm build` to verify all Next.js static and dynamic routes compile without errors.
- Commit to `dev`, push to `origin/dev`, and verify Vercel preview deployment (`target: null`).
- Merge `dev` to `prod`, push to `origin/prod`, and verify Vercel production deployment (`target: "production"`).
- Run live smoke health checks against `https://devfinity-crm.vercel.app` and `https://crm.devfinity.net`.
