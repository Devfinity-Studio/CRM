# Phase 48 - Plan 01: Global Design Tokens, Navigation Shells & Shared UI Primitives

## Tasks

### Task 1: Audit & Refactor Global CSS Tokens
- Audit `src/styles/globals.css`:
  * Define surface elevation levels (`--surface-1`, `--surface-2`, `--surface-3`) with glassmorphism blur and dark-mode isolation.
  * Ensure `--foreground` and `--background` tokens yield at least WCAG 2.1 AAA contrast (`7:1` for regular text).
  * Add WebKit autofill text color fix (`input:-webkit-autofill`).
  * Add safe area inset variables: `--safe-bottom: env(safe-area-inset-bottom, 0px)`.
  * Ensure focus rings are clearly visible across all backgrounds (`ring-2 ring-primary/50 ring-offset-2`).

### Task 2: Refactor UI Primitives for Mobile Ergonomics & Zero-Defect Contrast
- `button.tsx`:
  * Enforce minimum touch target on mobile: `h-11 sm:h-9 px-4 text-sm`.
  * Define high-contrast borders for `outline` and `ghost` variants.
  * Explicit contrast locking for `:hover`, `:active`, and `:disabled`.
- `input.tsx` & `textarea.tsx`:
  * Enforce `text-base sm:text-sm` to strictly prevent iOS Safari auto-zooming on focus.
  * High-contrast placeholder color (`placeholder:text-muted-foreground/80`).
  * Explicit border colors on focus (`focus-visible:border-primary focus-visible:ring-primary/40`).
- `card.tsx`:
  * Backdrop blur with solid/semi-solid tint ensuring text inside is always 100% legible regardless of underlying background.
  * Border color: `border-border/60 dark:border-border/40`.
- `badge.tsx`:
  * Glowing contrast status badges (`success`, `warning`, `destructive`, `outline`, `secondary`) with verified dark/light readability.
- `dialog.tsx` & `sheet.tsx`:
  * Dialog: on screens `< 640px`, anchor to bottom (`items-end sm:items-center`), `rounded-t-2xl sm:rounded-xl`, `max-h-[88dvh]`, with sticky header/footer.
- `table.tsx`:
  * Add horizontal touch-scroll container wrapper (`overflow-x-auto -mx-4 px-4 sm:mx-0 sm:px-0 no-scrollbar`) with `whitespace-nowrap`.
- `tabs.tsx`:
  * Horizontal scrolling tab strip on mobile with `overflow-x-auto no-scrollbar` and `shrink-0` on tabs.

### Task 3: Overhaul Navigation Shells
- `dashboard-layout.tsx`:
  * Desktop: Sleek glassmorphic sidebar rail with smooth hover/active indicators, organization switcher, and bottom user profile card.
  * Top bar: Notifications bell with unread badge, quick search trigger (`⌘K`), and breadcrumb navigation.
  * Mobile: Collapsible slide-over drawer with 44px tap targets + sticky bottom bar for quick section switches (Dashboard, Pipeline, Clients, Billing).
- `superadmin-layout.tsx`:
  * Harmonize with Stitch design tokens, organization switcher, and system status badge.
