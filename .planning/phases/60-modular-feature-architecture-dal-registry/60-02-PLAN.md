# Plan 60-02: Decoupled Feature Registry & Dynamic Module Boundaries

## Objective
Refactor feature components and landing pages into modular boundaries (`src/features/<feature-name>/`) and build a centralized Feature Registry (`src/lib/features/registry.ts`) supporting dynamic imports and runtime flag enablement.

## Proposed Changes

### 1. Central Feature Registry (`src/lib/features/registry.ts`)
- Define feature schema:
  - `key`: Identifier matching platform feature keys (`deals`, `clients`, `invoicing`, `quotes`, `inventory`, `subscriptions`, `automations`, `aiInsights`).
  - `name`: Display name.
  - `description`: Purpose and capability summary.
  - `route`: Primary URL path.
  - `category`: Classification (`sales`, `finance`, `operations`, `automation`, `intelligence`).
  - `defaultEnabled`: Baseline state.
  - `minRole`: Minimum required role.
- Provide lookup and evaluation helpers:
  - `getAllFeatures()`
  - `getFeature(key)`
  - `isFeatureAvailable(key, entitlements)`
  - `getAccessibleNavItems(entitlements, userRole)`

### 2. Feature Module Boundaries (`src/features/`)
- Establish self-contained modules:
  - `src/features/deals/`: Export `DealsBoardView`, `DealForecastView`, deal sheets, types.
  - `src/features/clients/`: Export `ClientsListView`, `ClientDetailView`, `ContactForm`, types.
  - `src/features/billing/`: Export `InvoicesView`, `QuotesView`, `SubscriptionsView`, invoice editors.
  - `src/features/inventory/`: Export `ProductsCatalogView`, `StockMovementsView`.
  - `src/features/automations/`: Export `AutomationsDashboardView`, rule editors.
  - `src/features/marketing/`: Export `CampaignsView`, ad tracking views.
- Each module provides an `index.ts` barrel file exporting public views, components, and types.

### 3. Dynamic Code-Splitting in App Routes
- Update `src/app/` page routes (`src/app/deals/page.tsx`, `src/app/clients/page.tsx`, `src/app/billing/invoices/page.tsx`, etc.) to import feature views dynamically using `next/dynamic` with skeleton loading fallbacks.

### 4. Automated Tests (`src/lib/features/__tests__/registry.test.ts`)
- Unit test suite verifying registry lookups, entitlement filtering, role visibility, and route resolution.
