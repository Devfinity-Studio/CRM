# Plan 56-01: Feature Flag Schema, Hierarchical Resolution Engine & Backend Guards

**Phase:** Phase 56 (Dynamic Feature Flags & Cascading Module Toggles)
**Task:** 56-01
**Dependencies:** None
**Target Files:**

- `src/server/api/routers/superadmin.ts`
- `src/server/api/routers/dashboard.ts`
- `src/server/api/__tests__/entitlements.test.ts`

## Goals
1. Add `featureFlags` text column to `globalSettings` in `src/server/db/schema.ts`.
2. Expand `FeatureKey` in `src/server/api/services/entitlements.ts` to include `hasQuotes`, `hasInvoicing`, and `hasAiInsights`.
3. Implement the three-tier resolution hierarchy in `getTenantEntitlements`:
   - Global Defaults (`globalSettings.featureFlags`) with kill-switch logic.
   - Subscription Plan Entitlements (`subscriptionPlans`).
   - Tenant Overrides (`tenantOverrides.featureOverrides`) providing VIP bypass.
4. Add tRPC procedures in `src/server/api/routers/superadmin.ts`:
   - `getGlobalFeatureFlags`: Get current global feature flags dictionary.
   - `updateGlobalFeatureFlags`: Update global feature flags in `globalSettings`.
   - `getTenantFeatureMatrix`: List organizations with effective flags, plan name, and overrides.
   - `setTenantFeatureOverride`: Set or clear individual feature override for a tenant.
5. Include effective feature flags in `dashboard.getLayoutData` so the client receives them on every layout load.
6. Expand Vitest test suite `src/server/api/__tests__/entitlements.test.ts` to verify cascading evaluation (global kill-switch, plan defaults, VIP overrides).
