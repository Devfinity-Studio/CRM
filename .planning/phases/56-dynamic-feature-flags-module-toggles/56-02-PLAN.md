# Plan 56-02: Super Admin Control Hub, Dynamic Sidebar Navigation & Route Redirection Guards

**Phase:** Phase 56 (Dynamic Feature Flags & Cascading Module Toggles)
**Task:** 56-02
**Dependencies:** Plan 56-01
**Target Files:**
- `src/app/superadmin/features/page.tsx`
- `src/components/layout/superadmin-layout.tsx`
- `src/components/layout/dashboard-layout.tsx`
- `src/app/inventory/products/page.tsx`
- `src/app/automations/page.tsx`
- `src/app/billing/subscriptions/page.tsx`

## Goals
1. Build the dedicated `/superadmin/features` page:
   - **Tab 1: Global Feature Toggles**: Card-based grid with 9 switches (`hasInventory`, `hasSubscriptions`, `hasAutomations`, `hasQuotes`, `hasInvoicing`, `hasCustomDomains`, `hasWebhooks`, `hasApiKeys`, `hasAiInsights`), descriptions, live impact counters, and one-click global kill-switch toggle with confirmation.
   - **Tab 2: Tenant Overrides Grid**: Organization selector/search, plan badge, and switchboard enabling superadmin to set custom ON/OFF overrides or reset to plan default.
2. Update `src/components/layout/superadmin-layout.tsx`:
   - Add `Features` link (`/superadmin/features`, icon: `ToggleLeft`) to sidebar navigation.
3. Update `src/components/layout/dashboard-layout.tsx`:
   - Consume effective feature flags from `layoutData.entitlements.features`.
   - Dynamically hide nav items when their module flag is disabled:
     - `/inventory/products` hidden if `hasInventory === false`
     - `/billing/subscriptions` hidden if `hasSubscriptions === false`
     - `/automations` hidden if `hasAutomations === false`
     - `/billing/invoices` hidden if both `hasInvoicing === false` and `hasQuotes === false`
4. Implement route redirection in module pages:
   - In `/inventory/products/page.tsx`, `/automations/page.tsx`, `/billing/subscriptions/page.tsx`: If the corresponding feature flag is `false`, redirect user to `/dashboard` and surface a friendly toast notification `The [Module] module is currently disabled for your workspace.`
5. Verify complete build and test suite:
   - `pnpm test` (all 18 test files passing)
   - `pnpm build` (all static & dynamic routes compiled cleanly)
