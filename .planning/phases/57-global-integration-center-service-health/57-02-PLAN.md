## Goals
1. **Super Admin Integrations Dashboard (`src/app/superadmin/integrations/page.tsx`)**:
   - Header with overall platform integration health status and "Refresh All Diagnostics" action.
   - 4 Interactive Service Health Cards:
     1. **Dodo Payments**: Live connectivity status (`OPERATIONAL`, `DEGRADED`, `DISCONNECTED`), environment badge (`test_mode` vs `live_mode`), response latency gauge, webhook signature verification status, and "Test Connection" button.
     2. **Svix Webhooks**: Connectivity badge, response latency, token configuration, and "Test Connection" button.
     3. **Neon Object Storage**: Bucket name, endpoint URL, regional latency, head-bucket response, and "Test Storage" button.
     4. **Email Service**: Delivery status, configured provider, latency, and "Test Email" button.
   - Platform Storage Consumption Panel:
     - S3 bucket details, path-style addressing indicator, estimated assets, and quick link to verify presigned upload generation.
   - Svix Operations & Triage Section:
     - View registered tenant apps in Svix.
     - Interactive form/button to dispatch a test webhook event (`test.ping`) and observe delivery result.
2. **Super Admin Navigation Update (`src/app/superadmin/layout.tsx`)**:
   - Add "Integrations" link to the primary Super Admin navigation bar between Features and Settings.
