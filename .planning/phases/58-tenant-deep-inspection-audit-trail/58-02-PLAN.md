- `src/server/api/routers/superadmin.ts`
- `src/app/superadmin/tenants/[id]/page.tsx`

- `src/app/superadmin/layout.tsx`

## Goals
1. **Tenant Deep Inspection Query (`src/server/api/routers/superadmin.ts`)**:
   - Implement `getTenantDeepInspection(orgId)`:
     - Returns organization profile (`name`, `slug`, `isActive`, `createdAt`, `logoUrl`)
     - Complete member roster joined with users (`name`, `email`, `role`, `joinedAt`)
     - Commercial stats: deal counts & won value, invoice counts & revenue
     - Subscription & Quotas: assigned plan, custom quotas, effective feature entitlements
     - Recent audit logs specifically targeting this tenant organization
2. **Tenant Deep Inspector Page (`src/app/superadmin/tenants/[id]/page.tsx`)**:
   - Organization overview header with active badge, impersonate button, and quick status toggle.
   - Metrics cards: Total Revenue, Open Pipeline, Active Members, Subscription Plan.
   - Tabs:
     - **Members**: User table with avatars, roles, emails, and member counts.
     - **Financials**: Invoices & deals summary with revenue breakdowns.
     - **Features & Quotas**: Effective feature flags and custom quota limits.
     - **Audit History**: Chronological log of Super Admin actions targeting this tenant.
3. **Audit Trail Viewer (`src/app/superadmin/audit/page.tsx`)**:
   - Filter bar: Action type dropdown, actor search, limit selector.
   - Audit event table with action badge, actor email, target type & ID, timestamp, and "View Metadata" button.
   - Metadata Inspection Dialog: Formatted JSON viewer with copy to clipboard.
4. **Super Admin Navigation Update (`src/app/superadmin/layout.tsx`)**:
   - Add "Audit Trail" to the navigation header.
5. **Verification**:
   - `pnpm test` passes 100%.
   - `pnpm build` compiles cleanly across all routes.
