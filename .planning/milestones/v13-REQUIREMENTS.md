# Milestone 13: UI Overhaul via Stitch MCP - Requirements

## 1. Goal
Revamp the entire DevCRM user interface using the Stitch MCP toolset. The goal is to establish a cohesive, modern design system, apply it across the app, and re-architect the core screens to feel premium and state-of-the-art.

## 2. Requirements

### Phase 37: Design System & Theming
- [ ] **Create Design System**: Use Stitch MCP to generate a new, comprehensive design system (colors, typography, spacing, component aesthetics) and upload it to the project.
- [ ] **Apply Global Styles**: Integrate the Stitch-generated design system into `globals.css` / Tailwind configuration.

### Phase 38: Layout & Navigation Redesign
- [ ] **Dashboard Layout**: Overhaul the main application layout (`DashboardLayout`), sidebar navigation, and header using the new design system.
- [ ] **Empty States & Loading**: Update skeleton loaders, empty states, and feedback toasts to match the premium feel.

### Phase 39: Sales Pipeline UI Refresh
- [ ] **Kanban Board**: Apply the new design system to the Deals drag-and-drop Kanban board (Phase 33-36 features). 
- [ ] **Deal Cards & Sheets**: Elevate the visual aesthetics of the Deal cards, Activity Timelines, and Slide-out Deal Sheets.

### Phase 40: CRM Client Profiles Overhaul
- [ ] **Client List**: Redesign the main Companies/Clients data table for better scannability and aesthetics.
- [ ] **Client Details**: Overhaul the Client profile page (`/clients/[id]`), integrating the unified points-of-contact and ledger views into the new design language.
